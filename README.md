# Análise de Viabilidade — Incapacidade e BPC/LOAS

Ferramenta interna do escritório **Arrais Advogados** para triagem de viabilidade de:

- Auxílio por Incapacidade Temporária (B31)
- Aposentadoria por Incapacidade Permanente (B32)
- Auxílio-Acidente (B91)
- BPC/LOAS — Idoso
- BPC/LOAS — Pessoa com Deficiência
- Restabelecimento ou Revisão de Benefício Cessado
- Triagem inicial (não sei qual benefício)

## Como acessar

A página é hospedada via GitHub Pages. URL pública depois da publicação.

- CF/88
- Lei 8.213/91 (Lei de Benefícios)
- Lei 8.742/93 (LOAS) com Lei 14.176/2021
- EC 103/2019
- Decreto 6.214/2007 com Decreto 12.534/2025
